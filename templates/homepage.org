** Customizing this page

nvEmacs rewrites this page when it exits, so edit the template, not this
file.  Copy =homepage.org= from the =templates= folder of nvEmacs to your
=nvemacs-template-directory= and change it there.  For Markdown, use
=homepage.md= and set =nvemacs-homepage-template= to that name.
